# Quizora — Interactive Quiz App 🎯

Quizora is an interactive quiz web application built using HTML, CSS, and JavaScript. It provides a simple and engaging platform where users can attempt quizzes, track their scores, view results, and create their own quizzes.

## 📌 Project Overview

Quizora is a front-end development project designed to make online quizzes more interactive and user-friendly. It features a clean interface, interactive quiz cards, category filters, quiz completion feedback, and a quiz creation interface.

The project focuses on JavaScript functionality, responsive user interface design, and interactive web development.

## ✨ Features

- **Interactive Quiz Cards:** Browse and select available quizzes.
- **Category Filters:** Filter quizzes by category.
- **Quiz Timer:** Track time while attempting a quiz.
- **Answer Selection:** Select answers and progress through quiz questions.
- **Score Tracking:** Calculate and display quiz results.
- **Results Dashboard:** View the final score and accuracy percentage.
- **Retry Quiz:** Attempt a completed quiz again.
- **Explore More:** Return to the quiz selection page.
- **Create Your Own Quiz:** Build and publish custom quizzes.
- **Personalized Profile:** Enter your name and email for a personalized demo experience.
- **Local Storage:** Store demo profile information in the browser.
- **Responsive Interface:** Designed for a clear and accessible user experience.

## 🚀 Getting Started

Follow these steps to run Quizora locally.

### Prerequisites

- A modern web browser
- Visual Studio Code (recommended)

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/YOUR-USERNAME/quizora-interactive-quiz-app.git
   ```

2. Navigate to the project directory:

   ```bash
   cd quizora-interactive-quiz-app
   ```

3. Open the folder in Visual Studio Code.

4. Open `index.html` in your browser, or use the Live Server extension in VS Code.
